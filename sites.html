    At least 8 characters. A longer, unique passphrase provides stronger protection.

    Import sites

    Choose a goTab encrypted backup or a legacy keyword-to-URL JSON file, up to 1 MB. Existing keywords will be skipped.

    Leave blank for backups using your current passphrase. Older backups need their original passphrase. A legacy JSON file is unencrypted; delete it securely if you no longer need it.
